# EIP-1967 — proxy slot reads

[EIP-1967](https://eips.ethereum.org/EIPS/eip-1967) defines
three fixed storage slots that TransparentUpgradeable proxies
use to record the implementation, the admin, and (for beacon
proxies) the beacon contract. Each slot is `keccak256("<name>") - 1`,
so reading them is a straight `eth_getStorageAt` against a
known constant — no ABI involved.

The address used below is USDC mainnet — a known
TransparentUpgradeable deployment.
