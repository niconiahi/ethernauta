# EIP-1014 — CREATE / CREATE2 address derivation

The pair `CREATE` (since Frontier) and `CREATE2` (EIP-1014)
define where a deployed contract lands:

- **CREATE**: `address = keccak256(rlp([sender, nonce]))[12:]`
- **CREATE2**: `address = keccak256(0xff ‖ sender ‖ salt ‖
  keccak256(init_code))[12:]`

CREATE2 is the basis for counterfactual deployments —
account abstraction factories (ERC-4337), Safe modules,
and EIP-6492 signatures all assume the deployed address
is knowable in advance. The demo shows both derivations
against EIP-1014 fixture vectors.

## The code (deriving addresses)

```ts
import {
  type Address,
  addressSchema,
  bytes32Schema,
} from "@ethernauta/core"
import {
  get_contract_address,
  get_create2_address,
} from "@ethernauta/eip/1014"
import { parse } from "valibot"

// CREATE — deterministic from (sender, nonce).
const create_address = get_contract_address({
  from: parse(
    addressSchema,
    "0x0000000000000000000000000000000000000042",
  ),
  nonce: 7n,
})

// CREATE2 — deterministic from (sender, salt,
// keccak256(init_code)). `bytecodeHash` is YOUR hash of
// the creation bytecode + constructor calldata; pre-hash
// before calling this.
const create2_address = get_create2_address({
  from: parse(
    addressSchema,
    "0x00000000000000000000000000000000deadbeef",
  ),
  salt: parse(
    bytes32Schema,
    "0x00000000000000000000000000000000000000000000000000000000cafebabe",
  ),
  bytecodeHash: parse(
    bytes32Schema,
    "0xd6fb717f7e270a360f5093ce6a7a3752183e89c9a9afe5c0cb54b204a3902895",
  ),
})
```

## Deploying through the wallet

`deploy_contract` ships in `@ethernauta/eip/1014` for the
signing half — it encodes constructor calldata and calls
`eth_signTransaction` with no `to` (the EVM rule for
creation transactions). The wallet fills `nonce` / `gas`
/ fees per the project invariant.

```ts
import { uint256 } from "@ethernauta/abi"
import { deploy_contract } from "@ethernauta/eip/1014"
import { eth_sendRawTransaction } from "@ethernauta/eth"

const signed_raw = await deploy_contract({
  bytecode,
  args: [uint256()],
  values: [42n],
})(signer({ chain_id }))

// then broadcast separately:
const hash = await eth_sendRawTransaction([signed_raw])(
  writer({ chain_id }),
)
```

`Signable<Bytes>` returns the signed raw transaction —
broadcast it with `eth_sendRawTransaction` to get the
hash, then derive the deployed address with
`get_contract_address({ from, nonce })`.
