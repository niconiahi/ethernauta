# Gas estimation — Arbitrum

`calculate_gas(chain, { kind: "arbitrum", tx })` issues a single
`eth_call` against the Nitro `NodeInterface` precompile at
`0x00000000000000000000000000000000000000C8`. The method
`gasEstimateComponents(to, false, data)` is virtual — the node
intercepts it and returns the four numbers Arbitrum cares about in
one shot:

- `gasEstimate` — total gas units needed.
- `gasEstimateForL1` — the portion that pays for posting the
  transaction's calldata to L1.
- `baseFee` — the L2 base fee at quote time.
- `l1BaseFeeEstimate` — ArbOS's current estimate of the L1 base
  fee it'll be charged.

The coarse helper drops `gasEstimateForL1` (we already have the
total) and surfaces `{ kind: "arbitrum", gas_estimate,
l1_base_fee_estimate, l2_base_fee }`.

## The code

```tsx
import { eip155_42161 } from "@ethernauta/chain"
import { calculate_gas } from "@ethernauta/gas"
import { useProvider } from "@ethernauta/react"

const provider = useProvider({ key: "my-app:picked-rdns" })
if (!provider) return <Picker />

const fees = await calculate_gas(eip155_42161, {
  kind: "arbitrum",
  tx: { to: "0x000…dEaD" },
})(provider.reader({ chain_id: "eip155:42161" }))

if (fees.kind !== "arbitrum") throw new Error("kind mismatch")
// fees.gas_estimate is the total gas units
```
