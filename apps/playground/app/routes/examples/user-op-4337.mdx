# ERC-4337 v0.7 — sign + submit a UserOperation

End-to-end account-abstraction flow on Sepolia. The dapp
builds a `UserOperation` for a SimpleAccount, computes the
EntryPoint v0.7 userOpHash, asks the wallet to sign it via
`personal_sign`, then submits the signed op to a public
bundler (Pimlico / Alchemy / your own) and polls for the
receipt.

## What's happening

1. The dapp builds a `UserOperation` (RPC shape — discrete
   gas + paymaster fields, unpacked).
2. `eth_estimateUserOperationGas` lets the bundler refine
   `callGasLimit`, `verificationGasLimit`, and
   `preVerificationGas` against current chain state.
3. `get_user_op_hash({ op, entryPoint, chainId })` packs
   the op (16-byte gas pair packing for `accountGasLimits`
   / `gasFees`, factory+factoryData → `initCode`, paymaster
   triple → `paymasterAndData`) and runs the v0.7
   double-keccak derivation.
4. `sign_user_op` asks the wallet to `personal_sign` the
   userOpHash. SimpleAccount + OpenZeppelin-ECDSA-recover
   accounts accept this directly. Accounts that recover
   from the raw hash without EIP-191 prefix need a custom
   signer.
5. `eth_sendUserOperation` posts the signed op to the
   bundler mempool. The bundler returns the userOpHash.
6. `eth_getUserOperationReceipt` rolls forward the include
   status — once the bundler bundles into a block, the
   receipt carries the on-chain tx hash.

## The code

```ts
import {
  address,
  bytes,
  encode_function_call,
  uint256,
} from "@ethernauta/abi"
import { eip155_11155111 } from "@ethernauta/chain"
import {
  ENTRY_POINT_V07_ADDRESS,
  eth_estimateUserOperationGas,
  eth_getUserOperationReceipt,
  eth_sendUserOperation,
  get_user_op_hash,
  sign_user_op,
  type UserOperation,
} from "@ethernauta/eip/4337"
import {
  create_reader,
  create_signer,
  create_writer,
  encode_chain_id,
  http,
} from "@ethernauta/transport"
import { bytes_to_hex } from "@ethernauta/utils"

const SEPOLIA_CHAIN_ID = encode_chain_id({
  namespace: "eip155",
  reference: eip155_11155111.chainId,
})
const SEPOLIA_REF_HEX = "0xaa36a7" as const

// Bundler talks ERC-4337 RPC; node talks regular eth_*.
// They're different transports — keep them separate.
const NODE_CHAINS = [
  {
    chainId: SEPOLIA_CHAIN_ID,
    transports: [
      http("https://ethereum-sepolia-rpc.publicnode.com"),
    ],
  },
]
const BUNDLER_CHAINS = [
  {
    chainId: SEPOLIA_CHAIN_ID,
    transports: [http(BUNDLER_URL)],
  },
]
const signer = create_signer(NODE_CHAINS)
const reader = create_reader(BUNDLER_CHAINS)
const writer = create_writer(BUNDLER_CHAINS)

// SimpleAccount.execute(target, value, data) calldata.
const callData = bytes_to_hex(
  encode_function_call({
    name: "execute",
    args: [address(), uint256(), bytes()] as const,
    values: [TARGET, 0n, "0x"] as never,
  }),
)

// 1. Draft op with dummy gas + signature for estimation.
const draft: UserOperation = {
  sender: SMART_ACCOUNT,
  nonce: "0x0",
  callData,
  callGasLimit: "0x186a0",
  verificationGasLimit: "0x186a0",
  preVerificationGas: "0xc350",
  maxFeePerGas: "0x6fc23ac00",
  maxPriorityFeePerGas: "0x77359400",
  signature: `0x${"00".repeat(65)}`,
}

// 2. Ask the bundler for tighter gas numbers.
const estimated = await eth_estimateUserOperationGas({
  op: draft,
  entryPoint: ENTRY_POINT_V07_ADDRESS,
})(reader({ chain_id: SEPOLIA_CHAIN_ID }))

const op = { ...draft, ...estimated }

// 3. Sign the userOpHash with the owner EOA. The wallet
//    pops personal_sign(userOpHash).
const signature = await sign_user_op({
  op,
  owner: OWNER_EOA,
  entryPoint: ENTRY_POINT_V07_ADDRESS,
  chainId: SEPOLIA_REF_HEX,
})(signer({ chain_id: SEPOLIA_CHAIN_ID }))

// 4. Submit to the bundler. Returns the userOpHash.
const userOpHash = await eth_sendUserOperation({
  op: { ...op, signature },
  entryPoint: ENTRY_POINT_V07_ADDRESS,
})(writer({ chain_id: SEPOLIA_CHAIN_ID }))

// 5. Poll. Once bundled, `receipt.receipt.transactionHash`
//    is the on-chain tx.
const receipt = await eth_getUserOperationReceipt(
  userOpHash,
)(reader({ chain_id: SEPOLIA_CHAIN_ID }))
```

## v0.7 packing rules (encoded for you)

| Field | Packing |
|------|---------|
| `accountGasLimits` | `verificationGasLimit (16) ‖ callGasLimit (16)` |
| `gasFees` | `maxPriorityFeePerGas (16) ‖ maxFeePerGas (16)` |
| `initCode` | `0x` if no factory, else `factory (20) ‖ factoryData` |
| `paymasterAndData` | `0x` if no paymaster, else `paymaster (20) ‖ pmVerification (16) ‖ pmPostOp (16) ‖ paymasterData` |

The library does the packing during `get_user_op_hash` so
the dapp only ever sees the unpacked RPC shape.
