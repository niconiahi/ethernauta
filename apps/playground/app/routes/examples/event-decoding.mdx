# Decoding contract event logs

`get_contract_events` composes three primitives:

1. `encode_event_topics({ name, args, indexed, values })`
   — builds the filter's `topics` slot, including
   `topic0 = keccak(canonical_signature)`.
2. `eth_getLogs` — the standard JSON-RPC read.
3. `decode_event_log({ name, args, indexed, topics, data })`
   — pairs each declared input with its value, reading
   indexed args from `topics[1..]` and non-indexed args
   from `data` via the ABI codec.

The result is `Readable<DecodedEventLog[]>` — same shape
as every other read in the library, with the dapp-side
HTTP transport.

## The code

```ts
import { address, uint256 } from "@ethernauta/abi"
import { eip155_1 } from "@ethernauta/chain"
import {
  eth_blockNumber,
  get_contract_events,
} from "@ethernauta/eth"
import {
  create_reader,
  encode_chain_id,
  http,
} from "@ethernauta/transport"

const MAINNET_CHAIN_ID = encode_chain_id({
  namespace: "eip155",
  reference: eip155_1.chainId,
})

const reader = create_reader([
  {
    chainId: MAINNET_CHAIN_ID,
    transports: [
      http("https://eth-mainnet.public.blastapi.io"),
    ],
  },
])
const ctx = reader({ chain_id: MAINNET_CHAIN_ID })

const USDC = "0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48"

// Scan the last few blocks so the example is bounded.
const head = BigInt(await eth_blockNumber()(ctx))
const from = head - 3n

// `args` is parallel to `indexed` — declares one ABI codec
// per event input. Transfer(address indexed, address indexed,
// uint256) → [address(), address(), uint256()] with
// indexed = [true, true, false].
const decoded = await get_contract_events({
  address: USDC,
  name: "Transfer",
  args: [address(), address(), uint256()],
  indexed: [true, true, false],
  fromBlock: `0x${from.toString(16)}`,
  toBlock: `0x${head.toString(16)}`,
})(ctx)

// decoded[i].args = [from, to, value], positional in the
// same order as `args` above.
```

## Indexed reference types

For `string` / `bytes` / arrays / tuples declared
`indexed`, the topic holds `keccak256(value)` — the
original value cannot be recovered from the log. The
codec surfaces this by returning the topic hash directly
for such positions.
