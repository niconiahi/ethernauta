# EIP-1167 — minimal proxy (clones)

[EIP-1167](https://eips.ethereum.org/EIPS/eip-1167) standardises
a 45-byte runtime that delegates every call to a hard-coded
target. Two operations:

- **Detection** — `is_clone(address)` fetches the contract's
  code and matches against the fixed prefix / suffix.
  `get_clone_target(address)` extracts the 20-byte target
  address embedded in the middle.
- **Deployment** — `deploy_clone(target)` returns the
  initialisation + runtime bytecode to put on a CREATE
  transaction. Broadcasting is the consumer's call
  (M3 path 1 or path 2).
