# @ethernauta/gas — fee estimation (EIP-1559)

`estimate_1559_fees({ base_fee_multiplier, priority_percentile })`
is the primitive for any EIP-1559 EVM chain that isn't part of an
L2 fee family. Mainnet, every testnet, every sidechain — anything
that prices gas exclusively via `eth_feeHistory` lands here.

For chains in an L2 fee family the consumer imports the matching
helper directly:

- **OP-stack** (Base, Optimism, Mode, Zora, Mantle, World Chain,
  Soneium, Lisk) → `calculate_gas_op_stack`.
- **Arbitrum** (One, Nova) → `calculate_gas_arbitrum`.
- **zkSync Era** (mainnet, Sepolia) → `calculate_gas_zksync`.

There is no central dispatcher — the consumer picks the helper
the same way they pick a chain. `@ethernauta/gas` also exports
`gas_family(chain)` and the `FamilyForChainId<Id>` conditional
type for consumers who want to branch on family at runtime or
type level.

The 1559 return shape:

- `base_fee_per_gas` — read from the latest entry of
  `baseFeePerGas`.
- `max_priority_fee_per_gas` — averaged from the requested
  percentile column of `reward[][]`.
- `max_fee_per_gas` — `base × multiplier + priority`, integer
  math via a 1e6 fixed-point scale.

The multiplier and the percentile are caller knobs. The library
ships no default — the dapp / wallet picks what they want.

## The code

```tsx
import { eip155_1 } from "@ethernauta/chain"
import { estimate_1559_fees } from "@ethernauta/gas"
import { useProvider } from "@ethernauta/react"
import { encode_chain_id } from "@ethernauta/transport"

const DISCOVERY_CHAIN_ID = encode_chain_id({
  namespace: "eip155",
  reference: eip155_1.chainId,
})

const provider = useProvider({ key: "my-app:picked-rdns" })
if (!provider) return <Picker />

const fees = await estimate_1559_fees({
  base_fee_multiplier: 1.5,
  priority_percentile: 10,
})(provider.reader({ chain_id: DISCOVERY_CHAIN_ID }))

// fees = { base_fee_per_gas, max_priority_fee_per_gas,
//          max_fee_per_gas }
```

## Path-2 (no wallet) is the same call

Same primitive against a public RPC reader — only the
transport-construction line changes:

```ts
import { eip155_1 } from "@ethernauta/chain"
import { estimate_1559_fees } from "@ethernauta/gas"
import { create_reader, http } from "@ethernauta/transport"

const reader = create_reader([
  {
    chainId: "eip155:1",
    transports: [http("https://ethereum-rpc.publicnode.com")],
  },
])
const fees = await estimate_1559_fees({
  base_fee_multiplier: 1.5,
  priority_percentile: 10,
})(reader({ chain_id: "eip155:1" }))
```
