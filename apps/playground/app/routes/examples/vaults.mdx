# ERC-4626 vault dashboards

Two real mainnet vaults — Morpho Steakhouse USDC and Yearn
yvUSDC v3 — read in a single multicall. For each vault we
batch six fields: `symbol`, `decimals`, `totalSupply`,
`totalAssets`, `convertToAssets(1 share)` (share price), and
`asset()` (underlying token address). Twelve reads across
two contracts, one roundtrip.
