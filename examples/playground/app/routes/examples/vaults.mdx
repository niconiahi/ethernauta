# ERC-4626 vault dashboards

Two real mainnet vaults — Morpho Steakhouse USDC and Yearn
yvUSDC v3 — read in a single multicall. For each vault we
batch six fields: `symbol`, `decimals`, `totalSupply`,
`totalAssets`, `convertToAssets(1 share)` (share price), and
`asset()` (underlying token address). Twelve reads across
two contracts, one roundtrip.

## The code for this example

```ts
import { eip155_1 } from "@ethernauta/chain"
import {
  decimals,
  symbol,
  totalSupply,
} from "@ethernauta/erc/20"
import {
  asset,
  convertToAssets,
  totalAssets,
} from "@ethernauta/erc/4626"
import {
  contract,
  create_multicall,
  encode_chain_id,
  http,
} from "@ethernauta/transport"

const VAULTS = [
  {
    label: "Morpho · Steakhouse USDC",
    address: "0xBEEF01735c132Ada46AA9aA4c54623cAA92A64CB",
  },
  {
    label: "Yearn · yvUSDC v3",
    address: "0xBe53A109B494E5c9f97b9Cd39Fe969BE68BF6204",
  },
] as const

const ONE_SHARE = "0x" + (10n ** 18n).toString(16)

const calls = VAULTS.flatMap((v) => {
  const ctx = contract({
    chain_id: MAINNET_CHAIN_ID,
    to: v.address,
  })
  return [
    symbol()(ctx),
    decimals()(ctx),
    totalSupply()(ctx),
    totalAssets()(ctx),
    convertToAssets({ shares: ONE_SHARE })(ctx),
    asset()(ctx),
  ] as const
})

const results = await multicall(calls)
```
