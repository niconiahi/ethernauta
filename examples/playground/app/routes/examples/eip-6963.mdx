# EIP-6963 — wallet discovery + persistence

Wallets dispatch `eip6963:announceProvider`; dapps dispatch
`eip6963:requestProvider` to nudge late ones. Each announce
carries `{ info: { name, rdns, uuid, icon }, provider }`.

The Provider object cannot be serialized — only the `rdns`
identifier can. Persistence is *re-discovery keyed by the
persisted identifier*: store rdns on pick, re-issue the
announce request on the next page load, match the
announcement, recover the live detail.

- **`set_provider_detail({ store, key, provider_detail })`** —
  persists the user's choice (writes only `detail.info.rdns`).
- **`get_provider_detail({ store, key, target?, ms? })`** —
  re-runs the 6963 handshake, filters by rdns, returns
  `EIP6963ProviderDetail | null` (null if the wallet
  uninstalled).
- **`clear_provider_detail({ store, key })`** — clears
  the persisted selection.

## The code

```ts
import {
  ANNOUNCE_EVENT,
  clear_provider_detail,
  type EIP6963AnnounceProviderEvent,
  type EIP6963ProviderDetail,
  get_provider_detail,
  REQUEST_EVENT,
  set_provider_detail,
  type Store,
  web_storage,
} from "@ethernauta/eip/6963"

const PICKED_KEY = "ethernauta:picked-wallet"

const store: Store = web_storage(window.localStorage)

// 1. Continuous listen — every announce lands in the list.
const providers: EIP6963ProviderDetail[] = []
window.addEventListener(ANNOUNCE_EVENT, (event) => {
  const detail =
    (event as EIP6963AnnounceProviderEvent).detail
  providers.push(detail)
})
window.dispatchEvent(new Event(REQUEST_EVENT))

// 2. On user pick, persist the rdns. Nothing else is
//    written — the live Provider stays in memory, the
//    identifier is what survives reloads.
function pick(provider_detail: EIP6963ProviderDetail) {
  set_provider_detail({
    store,
    key: PICKED_KEY,
    provider_detail,
  })
}

// 3. On a later page load, rehydrate by re-issuing the
//    6963 handshake and filtering by the stored rdns.
const provider_detail = await get_provider_detail({
  store,
  key: PICKED_KEY,
  ms: 200,
})
// provider_detail is null when the wallet is no longer installed.

// 4. Clear the persisted selection on disconnect / wallet
//    uninstalled / user request.
clear_provider_detail({
  store,
  key: PICKED_KEY,
})
```

The `Store` shape is `{ get, set, remove }` — synchronous
get/set/remove returning `string | null`. `window.localStorage`
fits via the `web_storage` adapter; in a Chrome MV3 background
a `chrome.storage.local`-backed wrapper works too; in tests, an
in-memory `Map`-backed shim works.
