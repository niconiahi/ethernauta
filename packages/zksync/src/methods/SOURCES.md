## Deferred to slice 4

- **`zks_getRawBlockTransactions`** — returns
  `Vec<zksync_types::Transaction>`, the internal mempool tx shape
  that carries EIP-712 metadata, paymaster params, factory deps,
  and the `customSignature` AA escape hatch. The schema is the
  same surface slice 4 needs for the 0x71 encoder + signer; binding
  the RPC method here would force authoring the Transaction schema
  twice. Ship together in slice 4.

## Bindings that have known deprecation / replacement

- `zks_getProtocolVersion` → `en_getProtocolVersionInfo`. Upstream
  marks the `zks_*` form deprecated. We still ship the binding
  because public nodes keep serving it; once we bind the `en_*`
  namespace we'll prefer the replacement.

## Operator-only / restricted methods

None in this namespace. Every `zks_*` method in the pinned trait is
callable from a public node — operator/admin RPCs live in separate
`en_*`, `unstable_*`, and `snapshots_*` namespaces that are out of
scope for this package today.
