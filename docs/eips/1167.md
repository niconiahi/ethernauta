# EIP-1167 — Minimal proxy

> [eips.ethereum.org/EIPS/eip-1167](https://eips.ethereum.org/EIPS/eip-1167)

EIP-1167 standardises a 45-byte runtime that delegates every call to a hard-coded target. It is what makes "clones" cheap — every instance is a fixed-shape proxy whose only state is the implementation address baked into the bytecode at deploy time.

```ts
import { parse } from "valibot";
import { AddressSchema } from "@ethernauta/core";
import { get_clone_target, is_clone } from "@ethernauta/eip/1167";
import { create_reader, encode_chain_id, http } from "@ethernauta/transport";
import { eip155_1 } from "@ethernauta/chain/eip155-1";

const CHAIN_ID = encode_chain_id({ namespace: "eip155", reference: eip155_1.chainId });
const reader = create_reader([
  { chainId: CHAIN_ID, transports: [http("https://ethereum-rpc.publicnode.com")] },
]);

const candidate = parse(AddressSchema, "0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48");

const detected = await is_clone(candidate)(reader({ chain_id: CHAIN_ID }));
const target = await get_clone_target(candidate)(reader({ chain_id: CHAIN_ID }));
void detected;
void target;
```

## Surface

| Export | Type | Purpose |
|---|---|---|
| `is_clone` | `(address) => Readable<boolean>` | Match the 45-byte runtime against `eth_getCode`. |
| `get_clone_target` | `(address) => Readable<Address \| NotFound>` | Extract the 20-byte target if the shape matches; `null` otherwise. |
| `deploy_clone` | `(target) => Bytes` | Compose init code + runtime for a CREATE transaction. Pure; consumer broadcasts. |
| `RUNTIME_PREFIX`, `RUNTIME_SUFFIX`, `INIT_PREFIX`, `RUNTIME_LENGTH_BYTES` | constants | Exported for consumers that want to compose their own checks. |

## Deploying a clone

`deploy_clone(target)` returns the creation bytecode. Broadcasting is the consumer's choice — path 1 (wallet sends) or path 2 (sign then broadcast).

```ts
import { parse } from "valibot";
import { AddressSchema, BytesSchema, UintSchema } from "@ethernauta/core";
import { deploy_clone } from "@ethernauta/eip/1167";
import { eth_signTransaction, eth_sendRawTransaction } from "@ethernauta/eth";
import type { Provider } from "@ethernauta/eip/1193";
import { create_provider, create_writer, encode_chain_id, http } from "@ethernauta/transport";
import { eip155_1 } from "@ethernauta/chain/eip155-1";

const CHAIN_ID = encode_chain_id({ namespace: "eip155", reference: eip155_1.chainId });
declare const provider: Provider;
const { signer } = create_provider(provider);
const writer = create_writer([
  { chainId: CHAIN_ID, transports: [http("https://ethereum-rpc.publicnode.com")] },
]);

const target = parse(AddressSchema, "0x43506849d7c04f9138d1a2050bbf3a0c054402dd");
const input = deploy_clone(target);

const signed = await eth_signTransaction([
  { to: parse(AddressSchema, "0x0000000000000000000000000000000000000000"), value: parse(UintSchema, "0x0"), input: parse(BytesSchema, input) },
])(signer({ chain_id: CHAIN_ID }));

const hash = await eth_sendRawTransaction([signed])(writer({ chain_id: CHAIN_ID }));
void hash;
```

The `to` field is unused on a contract-creation transaction at the wire layer, but the schema still requires an address; the zero address is the convention.

## Where this gets used

- **Factory patterns.** Mint thousands of cheap proxies that all delegate to one logic contract. Common in NFT collections, vault registries, vesting trees.
- **Discovery tooling.** Walk a factory's deployment log and classify which children are clones (and of what target) before reading their state.
- **Diff against a known-good target.** If `get_clone_target(address)` doesn't match the expected implementation, the proxy has been migrated.
