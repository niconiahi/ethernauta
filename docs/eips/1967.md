# EIP-1967 — Proxy storage slots

> [eips.ethereum.org/EIPS/eip-1967](https://eips.ethereum.org/EIPS/eip-1967)

EIP-1967 defines three fixed storage slots that upgradeable proxies use to record their implementation, admin, and beacon. Each slot is `keccak256("<name>") - 1`, picked to avoid collisions with any structured-storage layout the implementation might use. Reading them is a plain `eth_getStorageAt` against a known constant — no ABI involved, no proxy delegatecall needed.

```ts
import { parse } from "valibot";
import { AddressSchema } from "@ethernauta/core";
import {
  get_admin,
  get_beacon,
  get_implementation,
} from "@ethernauta/eip/1967";
import { create_reader, encode_chain_id, http } from "@ethernauta/transport";
import { eip155_1 } from "@ethernauta/chain/eip155-1";

const CHAIN_ID = encode_chain_id({ namespace: "eip155", reference: eip155_1.chainId });
const reader = create_reader([
  { chainId: CHAIN_ID, transports: [http("https://ethereum-rpc.publicnode.com")] },
]);

const proxy = parse(AddressSchema, "0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48");
const ctx = reader({ chain_id: CHAIN_ID });

const implementation = await get_implementation(proxy)(ctx);
const admin = await get_admin(proxy)(ctx);
const beacon = await get_beacon(proxy)(ctx);
void implementation;
void admin;
void beacon;
```

Each reader returns `Address | NotFound`. A zero slot — the case for an EOA, a non-proxy contract, or a proxy that simply doesn't use this slot — comes back as `null`, distinguishing "this is not a 1967 proxy" from a real implementation address.

## Surface

| Export | Type | Purpose |
|---|---|---|
| `get_implementation` | `(address) => Readable<Address \| NotFound>` | Read the implementation slot. |
| `get_admin` | `(address) => Readable<Address \| NotFound>` | Read the admin slot. |
| `get_beacon` | `(address) => Readable<Address \| NotFound>` | Read the beacon slot. |
| `IMPLEMENTATION_SLOT`, `ADMIN_SLOT`, `BEACON_SLOT` | `Bytes32` constants | Exported for consumers that want to compose their own slot reads. |

## What the slots are

| Slot | Value | Used by |
|---|---|---|
| `IMPLEMENTATION_SLOT` | `keccak256("eip1967.proxy.implementation") - 1` | TransparentUpgradeable, UUPS, and anything OZ-derived. |
| `ADMIN_SLOT` | `keccak256("eip1967.proxy.admin") - 1` | Only TransparentUpgradeable; UUPS proxies leave it zero. |
| `BEACON_SLOT` | `keccak256("eip1967.proxy.beacon") - 1` | Beacon proxies (a single beacon's implementation is shared across many proxies). |

The `- 1` is integer subtraction on the 32-byte hash and exists so that no preimage maps to the slot — the slot value is unreachable by any `keccak256` of a Solidity storage key.

## Where this gets used

- **Block explorers and audits.** "What's behind this proxy right now?" without delegating any calls.
- **Upgrade detection.** Watch the implementation slot and emit a UI banner ("This contract was upgraded 3 hours ago") when it changes.
- **Cross-chain sanity checks.** Compare implementation slots across L1 and L2 deployments of the same logical contract.
