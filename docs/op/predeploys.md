# Predeploys

OP Stack chains ship with a fixed set of system contracts at well-known `0x420…` addresses. Same code, same addresses, every OP Stack chain — Optimism, Base, Mode, Zora, Worldchain, Soneium, Lisk. This is what makes OP-Stack-wide tooling possible: bind the address once, the binding works on every chain in the family.

Authoritative reference: [Predeploys — OP Stack specs](https://specs.optimism.io/protocol/predeploys.html). Source: [`packages/contracts-bedrock/src/L2/`](https://github.com/ethereum-optimism/optimism/tree/develop/packages/contracts-bedrock/src/L2). ABIs in this package are pinned to [`op-contracts/v6.0.0`](https://github.com/ethereum-optimism/optimism/releases/tag/op-contracts%2Fv6.0.0) — see [`packages/op/src/predeploys/SOURCES.md`](https://github.com/niconiahi/ethernauta/blob/main/packages/op/src/predeploys/SOURCES.md) for the pinned SHA and bump cadence.

## Address registry

| Predeploy | Address | Purpose | Methods |
|---|---|---|---|
| [`GasPriceOracle`](https://specs.optimism.io/protocol/predeploys.html#gaspriceoracle) | `0x420…000F` | L1 fee math (`getL1Fee`, `baseFee`, `decimals`, `gasPrice`, scalars). Used by [`estimate_op_fees`](/op/gas) and [`estimate_l1_fee`](/op/gas). | 23 |
| [`L1Block`](https://specs.optimism.io/protocol/predeploys.html#l1block) | `0x420…0015` | Current L1 block context (`basefee`, `blobBaseFee`, `hash`, `number`, `timestamp`, `sequenceNumber`, batcher hash, blob-base-fee scalar). Populated by the sequencer every L2 block. | 24 |
| [`L2StandardBridge`](https://specs.optimism.io/protocol/predeploys.html#l2standardbridge) | `0x420…0010` | L2 side of the canonical bridge. View bindings here; write methods (`withdraw`, `bridgeERC20`, `finalize*`) are exposed as `Bridgeable<T>` verbs in [`@ethernauta/op/bridge`](/bridge/op). See [SOURCES.md](https://github.com/niconiahi/ethernauta/blob/main/packages/op/src/predeploys/SOURCES.md#l2standardbridge--subset-rationale). | 8 |
| [`L2CrossDomainMessenger`](https://specs.optimism.io/protocol/predeploys.html#l2crossdomainmessenger) | `0x420…0007` | Generic L1 ↔ L2 message passing primitive. | 24 |
| [`L1FeeVault`](https://specs.optimism.io/protocol/predeploys.html#l1feevault) | `0x420…001A` | Collects the L1 data fee surcharge. | 13 |
| [`SequencerFeeVault`](https://specs.optimism.io/protocol/predeploys.html#sequencerfeevault) | `0x420…0011` | Collects the L2 priority fee. | 14 |

Additional predeploys defined by the spec but not currently planned for binding (out of scope until a consumer surfaces):

- `LegacyMessagePasser` (`0x420…0000`) — pre-Bedrock relic, kept for archival reads.
- `DeployerWhitelist` (`0x420…0002`) — disabled post-Bedrock.
- `L2ToL1MessagePasser` (`0x420…0016`) — withdrawal initiation. Lands with the bridge phase.
- `OptimismMintableERC20Factory` (`0x420…0012`) — factory for canonical-bridged ERC-20s.
- `ProxyAdmin` (`0x420…0018`) — owns upgrade rights on the rest of the predeploys.
- `BaseFeeVault` (`0x420…0019`) — collects the L2 base fee.
- `SchemaRegistry` / `EAS` (`0x420…20…21`) — Ethereum Attestation Service. Out of scope here; see [EAS docs](https://docs.attest.org/).

Full canonical list: [predeploys.go in op-bindings](https://github.com/ethereum-optimism/optimism/blob/develop/op-bindings/predeploys/predeploys.go).

## How predeploy methods are bound

Same pattern as the ERC bindings — autogenerated from the canonical ABI, output one curried method per ABI entry. Bound paths:

```ts
import { contract } from "@ethernauta/transport"
import {
  GAS_PRICE_ORACLE_ADDRESS,
  getL1Fee,
} from "@ethernauta/op/predeploys/gas-price-oracle"

const callable = getL1Fee({ _data: unsigned_tx_bytes })(
  contract({ chain_id: CHAIN_ID, to: GAS_PRICE_ORACLE_ADDRESS }),
)
// → Callable<Uint256>
```

The `to` address is a constant — the predeploy lives at the same address on every OP Stack chain — so the binding is chain-agnostic. Same call site works on Base, Mode, Zora, Optimism, all of them.

Address constants and method bindings live behind per-predeploy subpaths. Six folders, six imports:

```ts
import { GAS_PRICE_ORACLE_ADDRESS, getL1Fee }      from "@ethernauta/op/predeploys/gas-price-oracle"
import { L1_BLOCK_ADDRESS, number, timestamp }     from "@ethernauta/op/predeploys/l1-block"
import { L1_FEE_VAULT_ADDRESS, totalProcessed }    from "@ethernauta/op/predeploys/l1-fee-vault"
import { L2_CROSS_DOMAIN_MESSENGER_ADDRESS,
         sendMessage }                             from "@ethernauta/op/predeploys/l2-cross-domain-messenger"
import { L2_STANDARD_BRIDGE_ADDRESS, messenger }   from "@ethernauta/op/predeploys/l2-standard-bridge"
import { SEQUENCER_FEE_VAULT_ADDRESS,
         RECIPIENT }                               from "@ethernauta/op/predeploys/sequencer-fee-vault"
```

Address constants alone are also re-exported from `@ethernauta/op` and `@ethernauta/op/predeploys` for convenience. **Method names like `version()` and `paused()` collide across predeploys**, so method bindings are only available on the per-predeploy subpath — never from the root barrel.

## Vendoring + codegen

Predeploy ABIs are vendored at a pinned commit SHA of `ethereum-optimism/optimism`. Run `pnpm --filter @ethernauta/op pull-contracts` to re-fetch at the current pin, then `pnpm regen` to rebuild the `methods/` folders. The pin (currently `op-contracts/v6.0.0` → `018f5ae9…`) and the bump procedure live in [SOURCES.md](https://github.com/niconiahi/ethernauta/blob/main/packages/op/src/predeploys/SOURCES.md). Never track `develop`.
